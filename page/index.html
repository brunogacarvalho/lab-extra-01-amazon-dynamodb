02 · ESTRUTURA

Chave primária composta

A tabela utiliza dois atributos para identificar exclusivamente cada registro.

PARTITION KEY

turma

String

Identifica a turma do estudante.
+
SORT KEY

aluno_id

String

Identifica o estudante dentro da turma.

A combinação de turma e aluno_id forma a chave primária composta.

03 · CONSULTAS

Query e Scan

Duas maneiras de recuperar informações armazenadas na tabela.

⌕

Query

Consulta itens utilizando o valor da chave de partição. Neste laboratório, foi utilizada para buscar estudantes por turma.

▤

Scan

Percorre os itens da tabela para recuperar registros, sem exigir um valor específico de chave de partição.
